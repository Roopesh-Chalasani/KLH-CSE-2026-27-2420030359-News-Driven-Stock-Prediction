# Dataset Sources

## GoEmotions

- Dataset: GoEmotions
- Source: Hugging Face
- Dataset ID: mrm8488/goemotions
- File: goemotions.csv
- Purpose: Text emotion classification and NLP analysis.

## TweetEval Sentiment

- Dataset: TweetEval Sentiment
- Source: CardiffNLP TweetEval
- Purpose: Sentiment classification.
- Files: train, validation, and test text and label files.

## Note

The datasets are maintained at their original sources. 
The repository contains the documented data-source references where the raw dataset files exceed the GitHub upload limit.
